## القرارات غير المحسومة التي ستُعرض بصيغة (Decision / Options / Recommendation / Reason)

حسب تعليمات الطلب، لن أخمّن بصمت — كل قرار معلّق سيظهر بهذه الصيغة داخل الوثيقة:

1. **State Management** — Options: Riverpod / BLoC / Provider. Recommendation متوقع: Riverpod (بساطة + قابلية اختبار + ملاءمة للطبقات).
2. **طبقة الوصول لـ SQLite** — Options: `sqflite` + SQL يدوي / `drift` (typed, migrations مدمجة). Recommendation متوقع: `drift` بسبب شرط الدستور "explicit, versioned migrations".
3. **نموذج دورة الميزانية** — هل تُنشأ صفوف `budget_cycles` مسبقًا للدورات القادمة أم صف واحد للدورة الجارية فقط تُغلق وتُفتح دورة جديدة؟ Recommendation: صف لكل دورة فعلية، تُنشأ عند بدايتها (يدويًا أو تلقائيًا عند أول استخدام بعد انتهاء السابقة).
4. **بدء الدورة التالية: تلقائي أم يدوي؟** — Recommendation: تلقائي عند أول فتح بعد انتهاء الدورة، مع تطبيق Carry-over المخزن في إعداد الدورة.
5. **سياسة Soft delete لكل جدول** — أي الجداول Sync-ready (expenses, categories, budget_cycles, shopping_lists, shopping_list_items) وأيها محلي فقط (settings).
6. **الملاحة** — Bottom navigation (Home / Expenses / Lists / Stats) مع Budget وSettings كنقاط دخول من Home وSettings، لتقليل عدد التبويبات.
7. **قواعد تقريب المبالغ** — integer minor units + decimals لكل عملة؛ تعريف سلوك Quantity × Unit Price غير الصحيح (قرار تقريب موحد).
